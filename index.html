2 · Handshake 挖掘 —

連上之後 0x0A11 和 0xFFF2 會自動訂閱 notify。
→ 現在按一次玩具的電源鍵，看下面有沒有東西跑進來。
來源最後收到 / 讀到#
0x0A11—0
0xFFF2—0

舊 SDK 的 0x0A0F Key state 在這台上不存在，所以授權一定是走 0x0A11。 按電源鍵之後如果 0x0A11 吐出非零位元組，把它寫回去很可能就是那段 password handshake。
